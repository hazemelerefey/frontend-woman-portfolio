# Shahd Khairy Portfolio

A motion-led portfolio for Shahd Khairy, a full-stack MERN developer based in Cairo, Egypt.

## Stack

- Next.js 16 and React 19
- TypeScript
- GSAP and ScrollTrigger
- Tailwind CSS 4

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality Checks

```bash
npm run typecheck
npm run build
```
